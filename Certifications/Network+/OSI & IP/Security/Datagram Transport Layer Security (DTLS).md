DTLS is a communications protocols providind security to datagram-based applications by allowing them to communicate in a way designed to prevent eavesdropping, tampering, or message forgery. The DTLS protocol is based on the stream oriented [[Transport Layer Security (TLS)]] protocol and is intended to provide similar securit guarantees. 

The DTLS protocol presevers the semantics of the underlying transport and the application does not suffer from the delays associated with stream protocols, but because it uses [[Internet Protocol Suite (TCP IP)#User Datagram Model (UDP)|User Datagram Protocol (UDP)]] or [[Stream Control Transmission Protocol (SCTP)]], the application has to deal with packet reordering, loss of datagram and data larger than the size of a datagram [[Packet|network packet]].
