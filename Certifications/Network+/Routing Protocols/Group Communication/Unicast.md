In computer networking, unicast is a [[One-to-one|one-to-one transmission]] from one point in the network to another point; that is, one sender and one receiver, each identified by a network address. 

Unicast is in contrast to [[Multicast]] and [[Broadcast]] which are one-to-many transmissions.

[[Internet Protocol Suite (TCP IP)#Internet Protocol (IP)|Internet Protocol]] unicast delivery methods such as [[Internet Protocol Suite (TCP IP)#Transmission Control Protocol (TCP)|Transmission Control Protocol (TCP)]] and [[Internet Protocol Suite (TCP IP)#User Datagram Model (UDP)|User Datagram Protocol (UDP)]] are typically used.
