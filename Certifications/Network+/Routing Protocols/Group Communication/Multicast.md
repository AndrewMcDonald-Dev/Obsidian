In computer networking, multicast is a type of group communication where data transmission is addressed to a group of destination computers simultaneously. Multicast can be [[One-to-many]] or [[Many-to-many]] distribution. Multicast differs from physical layer [[Point-to-multipoint Communication]].

Group communication may either be [[OSI Model#Application|application layer]] multicast or network-assisted multicast, where the latter makes it possible for the source to efficiently send to the group in a single transmission. Copies are automatically created in other network elements, such as [[Router|routers]], [[Switch|switches]] and [[Cellular Network]] base stations, but only to network segments that currently contain members of the group. Network assisted multicast may be implemented at the [[OSI Model#Data Link|data link layer]] using one-to-many addressing and switching such as [[Ethernet Multicast Addressing]], [[Asynchronous Tranfer Node]], point-to-multipoint virtual circuits or [[InfiniBand]] multicast. Network-assisted multicast may also be implemented at the [[Internet Protocol Model (IP Model)#Internet|Internet layer]] using [[Internet Protocol Suite (TCP IP)#Internet Protocol (IP)#IP Multicast|IP multicast]]. In IP multicast the implementation of the multicast concept occurs at the IP routing level, where routers create optimal distribution paths for [[Datagram|datagrams]] sent to a multicast destination address.

Multicast if often employed in [[Internet Protocol Suite (TCP IP)#Internet Protocol (IP)|Internet Protocol (IP)]] applications of streaming media, such as IPTV and multipoint videoconferencing.

## Ethernet
[[Frame#Ethernet Frame|Ethernet frames]] with a value of 1 in the least-significant bit of the first octet of the destination address are treated as multicast frames and are flooded to all points on the network. This mechanism constitutes multicast at the data link layer. This mechanism is used by [[Internet Protocol Suite (TCP IP)#IP multicast|IP multicast]] to achieve one-to-many transmission for IP on [[802.3 (Ethernet)|Ethernet]] networks. Modern Ethernet controllers filter received packets to reduce CPU load, by looking up the hash of a multicast destination address in a table, initialized by software, which controls whether a multicast packets is dropped or fully received.

Ethernet multicast is available on all Ethernet networks. Multicast span the [[Broadcast#Broadcast Domain|Broadcast Domain]] of the network. [[Multiple Registration Protocol (MRP)]] can be used to control Ethernet multicast delivery.

## IP 
IP multicast is a technique for [[One-to-many]] communication over an IP network. The destination nodes send [[Internet Group Management Protocol (IGMP)]] *report* and *leave* messages, for example in the case of IPTV when hte user changes from one TV channel to another. IP multicast scales to a larger receiver populatpion by not requiring prior knowledeg of who or how many receivers there are. Multicast uses network infrastructure efficiently by requiring the source to send a packet only once, even if it needs to be delivered to a large number of receivers. The nodes in the network take care of replicating the packet to reach multiple receivers only when necessary.

The most common [[Internet Protocol Model (IP Model)#Transport|transport layer]] protocol to use multicast addressing is [[Internet Protocol Suite (TCP IP)#User Datagram Model (UDP)|User Datagram Protocol (UDP)]]. By its nature, UDP is not *reliable* messages may be lost or delivered out of order. By adding loss detection and retransmission mechanisms, reliable multicast has been implemented on top of UDP or [[Internet Protocol Suite (TCP IP)#Internet Protocol (IP)|Internet Protocol]] of the [[Object Management Group (OGM)]] [[Data Distribution Service (DDS)]] standard, as well as by special transport protocols such as [[Pragmatic General Multicast (PGM)]].

IP multicast is always available within the local subnet. Achieving IP multicast services over a wider area requires multicasting routing. Many network, including the internet, do not support multicast routing. Multicast routing functinality is available in enterprise-grade network equipment but typically needs to be configured by a network administrator. The [[Internet Group Management Protocol (IGMP)]] is used to control IP multicast delivery.

## Application Layer
Application layer multicast overlay services are not based on IP multicast or data link layer multicast. Instead they use multiple [[Unicast]] transmissions to simulate a multicast. [[Internet Relay Chat (IRC)]] implements a single [[Spanning Tree Protocol (STP)|spanning tree]] across its [[Overlay Network]] for all conference groups.

## Wireless Networks
Wireless communications are inherently broadcasting media. However, the communication serivec provided may be [[Unicast]], mulitcast, or [[Broadcast]], depending on if the data is addressed to an individual node, a specific group of nodes, or all nodes in the covered network, respectively.
