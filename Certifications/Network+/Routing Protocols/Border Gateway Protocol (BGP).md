Border Gateway Protocol is a standardized [[Exterior Gateway Protocol]] designed to exchange routing and reachability information among autonomous systems on the Internet. BGP is classified as a path-vector routing protocol, and it makes routing decisions based on paths, network policies, or rule-sets configured by a network administrator.

BGP neighboars, called peers, are established by manual configuration among [[Router|routers]] to create a [[Internet Protocol Suite (TCP IP)#Transmission Control Protocol (TCP)|TCP]] sessions on port 179. A BGP speaker sends 19-byte keep-alive messages every 30 seconds to maintain the connection. Among routing protocols, BGP is unique in using TCP as its routing protocol.

BGP is the routing protocol backbone of the internet. BGP is responsible whenever someone submits data via the internet to look at all of the available paths that data could travel and picking the best route, which usually means hopping between autonomous systems. In this sense BGP works directly in conjunction with [[Domain Name Service (DNS)]] by DNS functioning like a list of addresses and BGP being the delivery service that gets the data to those addresses.
