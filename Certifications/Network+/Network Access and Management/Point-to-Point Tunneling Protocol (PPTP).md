Point-to-Point Tunneling Protocol (PPTP) is an obsolete method for implementing [[Virtual Private Network (VPN)]].  PPTP has many well known security issues. PPTP uses a [[Internet Protocol Suite (TCP IP)#Transmission Control Protocol (TCP)|TCP]] control channel and a Generic Routing Encapsulation tunnel to encapsulate [[Point-to-Point Protocol (PPP)|PPP]] packets. Many modern VPNs use various forms of [[Internet Protocol Suite (TCP IP)#User Datagram Model (UDP)|UDP]] for this same functionality.
