The Challenge-Handshake Authentication Protocol (CHAP) is an authentication protocol originally used by [[Point-to-Point Protocol (PPP)]] to validate users. CHAP is also carried in other authentication protocols such as [[RADIUS]] and [[Diameter]].

Almost all network operating systems support PPP with CHAP as do most ntework access servers. As the PPP sends data unencrypted CHAP is vulnerable to any attacker who can observe the PPP session.

[[Microsoft Challenge Handshake Authentication Protocol (MS-CHAP)|MS-CHAP v2]] is similar to CHAP but uses a differnt hash algorithm, and allows for each party to authenticate the other.
