MS-CHAP is the microsoft version of the [[Challenge Handshake Authentication Protocol (CHAP)]]. MS-CHAP is used as one authentication option in Microsoft's implementation of the [[Point-to-Point Tunneling Protocol (PPTP)]] protocol for [[Virtual Private Network (VPN)]]s. It is also used as an authentication option with [[RADIUS]] servers which are used with [[802.11 Specification (Wi-Fi)]] security using the [[Wi-Fi Protected Access (WPA)#WPA-Enterprise|WPA-Enterprise]] protocol. It is further used as the main authentication option of the [[Protected Extensible Authentication Protocol (PEAP)]].
